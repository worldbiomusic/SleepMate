# 단축어로 수면 데이터 넘겨주기 (무료 Apple ID용)

무료 Apple ID로 사이드로딩한 앱은 HealthKit 권한이 빠져서 건강 데이터를 직접 읽을 수 없습니다.
그래서 Apple의 **단축어** 앱이 수면 기록을 읽고, 텍스트로 정리해 **클립보드**에 담은 뒤 SleepMate를 엽니다.
SleepMate는 열리자마자 클립보드를 읽어 저장합니다.

```
[단축어] 건강 샘플 찾기(수면 분석) → 한 줄씩 텍스트로 → 클립보드 복사 → sleepmate://import 열기
[SleepMate] 클립보드 읽기 → 해석 → 저장 → 화면 표시
```

한 줄 형식: `시작날짜|종료날짜|값|소스`
예: `2026-11-13T00:12:00+09:00|2026-11-13T00:47:00+09:00|코어|Apple Watch`

---

## 1. 단축어 만들기 (한 번만, 약 10분)

1. **단축어** 앱 → 오른쪽 위 **+**
2. 맨 위 제목을 눌러 이름을 정확히 **`SleepMate 동기화`** 로 바꿉니다.
   앱의 ↻ 버튼이 이 이름으로 단축어를 실행하므로 띄어쓰기까지 같아야 합니다.

### 동작 ① 건강 샘플 찾기
1. 아래 검색창에 `건강 샘플 찾기` → 추가
2. **유형**(파란 글씨) 탭 → **수면 분석**
3. **필터 추가** → `시작 날짜` · `지난` · `14` · `일`
   (처음엔 7일로 해도 됩니다. 기간이 길수록 실행이 느려집니다)
4. **정렬 기준**: `시작 날짜`, **순서**: `오래된 항목부터`
5. **제한**: 끔

### 동작 ② 각 항목을 반복
1. `각 항목을 반복` 추가 (입력이 자동으로 '건강 샘플'로 잡힙니다)
2. 아래에 `반복 종료`가 자동으로 생깁니다.

### 동작 ③ 반복 안에 텍스트
`반복` 과 `반복 종료` **사이에** `텍스트` 동작을 넣고, 아래 순서로 채웁니다.

| 순서 | 넣는 방법 |
|---|---|
| 1 | 텍스트 칸 탭 → 키보드 위 변수 막대에서 **반복 항목** 선택 → 그 변수를 다시 탭 → **시작 날짜** 선택 → 한 번 더 탭 → **날짜 형식: ISO 8601**, **시간 포함: 켬** |
| 2 | 키보드로 `|` 입력 (세로 막대, 숫자·기호 키보드 두 번째 페이지) |
| 3 | 다시 **반복 항목** → **종료 날짜** → 형식 **ISO 8601**, 시간 포함 켬 |
| 4 | `|` 입력 |
| 5 | **반복 항목** → **값** |
| 6 | `|` 입력 |
| 7 | **반복 항목** → **소스** (없으면 생략해도 됩니다) |

완성되면 이렇게 보입니다: `[시작 날짜]|[종료 날짜]|[값]|[소스]`

> 날짜 형식을 ISO 8601로 바꾸지 않아도 한국어 기본 형식(`2026. 11. 13. 오전 1:05`)은 앱이 읽을 수 있습니다.
> 다만 ISO 8601이 가장 확실합니다.

### 동작 ④ 텍스트 결합
`반복 종료` **아래에** `텍스트 결합` 추가
- 입력: **반복 결과**
- 구분자: **새로운 줄**

### 동작 ⑤ 클립보드에 복사
`클립보드에 복사` 추가 → 입력: **결합된 텍스트**

### 동작 ⑥ URL 열기
1. `URL` 동작 추가 → 내용에 `sleepmate://import` 입력
2. `URL 열기` 동작 추가 (입력: URL)

### 최종 모양
```
건강 샘플 찾기  (수면 분석, 지난 14일, 시작 날짜 오래된 순, 제한 없음)
각 항목을 반복
    텍스트: [시작 날짜]|[종료 날짜]|[값]|[소스]
반복 종료
텍스트 결합  (반복 결과, 새로운 줄)
클립보드에 복사  (결합된 텍스트)
URL  sleepmate://import
URL 열기
```

## 2. 처음 실행

1. 단축어 편집 화면 오른쪽 아래 **▶︎** 실행
2. "건강 데이터에 접근하도록 허용" → **허용** (수면 분석 읽기 켜기)
3. "SleepMate에서 열겠습니까?" → **열기**
4. SleepMate가 클립보드를 읽을 때 "붙여넣기 허용" → **붙여넣기 허용**
5. 화면에 지난밤 기록이 나오면 성공입니다.

붙여넣기 질문을 매번 받지 않으려면: **설정 → 앱 → SleepMate → 다른 앱에서 붙여넣기 → 허용**

이후에는 SleepMate 오른쪽 위 **↻** 버튼을 누르면 단축어가 실행되고 다시 SleepMate로 돌아옵니다.
↻ 버튼을 **길게 누르면** 클립보드 가져오기, export.xml 열기 같은 다른 방법이 나옵니다.

---

## 3. (선택) 매일 아침 자동으로

1. 단축어 앱 → 아래 **자동화** 탭 → **+** (또는 '새로운 자동화')
2. 둘 중 하나 선택
   - **알람** → '중단됨' → 매일 쓰는 기상 알람 선택 (알람을 끄면 실행)
   - **특정 시간** → 오전 8:00, 매일
3. **즉시 실행** 선택 (실행 전 확인 끔)
4. 다음 → **SleepMate 동기화** 선택 → 완료

아이폰이 잠겨 있으면 앱 열기가 잠금 해제 뒤로 미뤄질 수 있습니다.
자동화로 단축어가 실행되면 데이터는 클립보드에 담겨 있으므로, 나중에 앱에서 ↻ 길게 누르기 → **클립보드에서 가져오기**를 써도 됩니다.

## 4. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| ↻를 눌렀는데 "단축어를 찾을 수 없음" | 단축어 이름이 정확히 `SleepMate 동기화`인지 (띄어쓰기 포함) |
| "수면 기록을 하나도 읽지 못했습니다" | 앱 왼쪽 위 로그 화면 → **해석 실패한 줄 예**를 확인. 대부분 `|`가 빠졌거나 날짜 대신 다른 값이 들어간 경우 |
| 건강 샘플이 0개 | 설정 → 건강 → 데이터 접근 및 기기 → **단축어** → 수면 켜기. 건강 앱에 수면 기록이 실제로 있는지도 확인 |
| 단축어 실행이 오래 걸림 | 필터를 `지난 7일`로 줄이기 |
| 클립보드가 비어 있다고 나옴 | 단축어의 '클립보드에 복사' 입력이 **결합된 텍스트**인지 확인 |
| 같은 밤이 두 번 더해져 보임 | 앱이 Apple Watch 기록을 우선 쓰고 겹치는 시간은 합쳐서 계산함. 그래도 이상하면 로그를 보내 주세요 |

## 5. 대안: 건강 데이터 내보내기 (과거 기록 한꺼번에)

1. **건강** 앱 → 오른쪽 위 프로필 사진 → 맨 아래 **모든 건강 데이터 내보내기** → 내보내기 → **파일에 저장**
2. **파일** 앱에서 `내보내기.zip`을 탭해 압축 해제 → 폴더 안에 `내보내기.xml` (또는 `export.xml`)
3. SleepMate → ↻ 길게 누르기 → **건강 데이터 내보내기 파일 열기** → 그 xml 선택
4. 최근 60일 수면 기록을 한 번에 가져옵니다. 파일이 크면 몇십 초 걸릴 수 있습니다.

## 6. 추가 단축어 (시나리오 02 · 04용, 선택)

### SleepMate 알람 (알람 탭의 "시계 앱에 알람 만들기" 버튼용)
앱이 `07:30` 같은 시각을 단축어 입력으로 넘겨줍니다.

1. 단축어 앱 → **+** → 이름을 정확히 **`SleepMate 알람`**
2. 동작 추가: **알람 생성** (시계)
3. **시간** 칸을 탭 → 변수 막대에서 **단축어 입력** 선택
4. 레이블은 `SleepMate` 정도로 입력
5. (처음 한 번) 단축어 정보(ⓘ) → **공유 시트에 표시**는 꺼도 됩니다

```
알람 생성   시간: [단축어 입력]   레이블: SleepMate
```

### SleepMate 취침 모드 (취침 준비 탭의 "취침 모드 켜기" 버튼용)
1. 단축어 앱 → **+** → 이름을 정확히 **`SleepMate 취침 모드`**
2. 동작 추가: **집중 모드 설정** → **수면** · **켬**
3. 동작 추가: **밝기 설정** → 30%
4. (선택) **음악 재생** 또는 **다크 모드 설정**

```
집중 모드 설정   수면 · 켬 · 끌 때까지
밝기 설정   30%
```
