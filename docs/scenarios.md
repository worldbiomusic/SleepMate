# 시나리오별 기능 (MVP 골격)

계획서의 흐름 **DATA → CONTEXT → DECISION → ACT** 와 판단 구조 **EVENT → REASON(규칙/경량 AI/LLM) → GUARD → ACT** 를 따라 탭마다 하나의 시나리오를 담았습니다.
각 로직은 한 파일에 모여 있어서 나중에 세부 규칙만 바꾸거나 LLM으로 교체하기 쉽습니다.

|---|---|---|

| 오늘 | 01 다음 날 행동·일정 추천 | `Scenario01/DayPlanner.swift`, `Scenario01/TodayView.swift` |

## 공통
- **Context 3종**
  - 장기 `UserProfile`: 목표 수면, 취침 목표, 준비·이동 시간, 화면 목표, 알람 선호, 음악 취향, 고정 일정 키워드
  - 일간 `DailyContext`: 피로도 1~5, 기분, 화면 사용 기록 (매일 자동으로 새로 시작, 30일 보관)
  - 실시간 `RealtimeContext`: 현재 시각, 취침까지 남은 시간, 다음 일정 (저장하지 않고 계산)
- **수면 점수** (0~100) = 시간 50 + 효율 20 + 단계 구성 15 + 규칙성 15
- **GUARD 정책** (`AgentGuard`)
  - 고정 일정(수업·회의·약속, 참석자 있는 일정)은 절대 옮기지 않음
  - 일정 변경은 반드시 사용자 승인
  - 저녁 알림은 최대 N개(기본 3)
  - 사용자가 정한 알람이 항상 우선
- **에이전트 기록**: 판단 경로(규칙/경량 AI/LLM)와 GUARD 결과를 설정 → 에이전트 판단 기록에서 확인 (발표 시연용)
- **피드백 · 평가 지표**: 도움 됐어요·나중에·건너뛰기·적용·거절을 기록하고 14일 수락률을 보여줌. 2번 이상 건너뛴 추천은 뒤로 밀림 (개인화 1단계)

## 01 다음 날 행동·일정 추천 (오늘 탭)
- **발생 조건**: 수면 기록 도착 / 탭 열기
- **Context**: 수면 점수, 7일 평균, 오늘 캘린더(EventKit), 피로도, 기분, 과거 피드백
- **추천**: 자연광 산책(첫 일정 40분 전), 카페인 컷오프, 규칙적 식사, 연속 일정 뒤 휴식, 20분 낮잠, 오늘 밤 취침 목표
- **일정 조정안**: 수면 부족 신호가 있으면 오전의 '조정 가능' 긴 작업을 오후 빈 시간으로 옮기고, 2시간 이상 연속 일정 뒤에 15분 휴식을 추가. **적용**을 눌러야 캘린더에 반영됨
- **데이터 부족 시**: "판단하기 어려워요" 안내
- **나중에**: Notion 할 일 연동, LLM으로 조정안 생성

## 02 취침 전 화면 관리 (취침 준비 탭)
- **개입 단계**: 취침 90분 전(패턴 안내) → 60분 전(화면 목표 확인, 알림 버튼 +5/+10/오늘은 여기까지) → 30분 전(준비 시작)
- **화면 목표 카운터**: 처벌이 아닌 안내 톤 메시지
- **늦게 잘 경우 가정형 시각화**: 취침 +0/30/60/90분일 때 내일 기상까지 수면 시간
- **준비**: 단축어 'SleepMate 취침 모드' 실행 버튼, 기분에 맞는 수면 음악 3곡 검색
- **제약**: 앱 사용량 자동 측정(Screen Time, Family Controls)은 유료 계정 + Apple 승인이 필요해 MVP에선 직접·알림 기록

## 04 맞춤형 기상 알람 (알람 탭)
- **계산**: 내일 첫 고정 일정 − 준비 − 이동 = 기상 (최소 기상 시각 보장, 5분 단위), 기상 − 목표 수면 − 15분 = 취침 목표
- **실행**: 단축어 'SleepMate 알람'으로 **시계 앱에 진짜 알람** 생성 (무음 모드·오프라인에서도 동작) + 백업 알림(선택)
- **선호**: 알람 방식·알람음 저장
- **선택 기능**: 수면 단계 기반 최적 기상은 측정 오차 때문에 비활성

## 05 읽어주는 수면 요약 (홈 탭)
- GOOD MORNING 카드: 점수 링, 점수 세부, 평균 대비, 오늘의 추천 1개, **수면 요약 듣기**
- 수면 코치: 기본 분석(오프라인) 또는 Claude(Haiku) 요약, 한국어 음성
- 최근 7일 막대 차트 + 목표선
- 단축어 자동화(알람 끌 때) + "가져온 뒤 자동으로 읽어주기" = 아침 자동 브리핑
